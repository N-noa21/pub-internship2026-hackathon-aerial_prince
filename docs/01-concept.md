# 01. コンセプトとゲームループ

> 一覧に戻る: [README.md](README.md)

## ひとことで言うと

プレイヤーは**わがままな王子様**。無茶な要求を口にすると、**5 人の家臣**が献上品を持って謁見の場に列をなしてやってくる。
気に入らない献上品は片っ端から**「打ち首だ！」**。最後に採用した一品と、斬った数によって、その後の国の運命が語られる。

コアの快感は 3 つ。

1. わがままを言う気持ちよさ
2. 大量の提案をバッサバッサと切り捨てる気持ちよさ（打ち首）
3. 提案そのもののバカバカしさ（実在商品のズレた献上）

## ゲームループ

```
[0] タイトル画面              「下民ショッピング」＋ START ボタン
        ↓
[1] わがままを入力            "でっかい城が欲しいのじゃ"
        ↓
[2] 家臣 5 人が献上品を用意     商人 / 貴族 / 騎士 / 農民 ／ 最後に宰相
        ↓
[3] 謁見の場に列をなす         5 人が順番待ちの列に並び、1 人ずつ献上する
        ↓
[4] 打ち首 or 採用            気に入らない → 打ち首（退場演出）／気に入った → 採用して終了へ
        ↓                     （任意）「なぜ斬った？」「なぜ選んだ？」を一言もらう
        ↓
[5] エンディング / レポート     「あなたはこういう王子ですね」＋その後の国の運命
```

## 体験の原則

- **プレイヤーの必須操作は、最初にわがままを 1 回入力するだけ。** 以降は「選ぶ／斬る」に専念させる。
- 理由の入力は**任意**。答えるほどエンディングが面白くなる（[02-mechanics.md](02-mechanics.md#判決理由任意入力)）。
- **1 プレイ 2 分以内**を目安にする（ハッカソンの展示・デモで回すため）。
- 献上する家臣は**5 人固定**。これによって次が決まる。
  - 列の長さが固定なのでテンポと UI が設計しやすい
  - 毎回同じ顔ぶれなのでキャラが立ち、「誰を斬ったか」がエンディングで意味を持つ
  - 生成は「5 人分を 1 回で」と固定でき、レイテンシとコストの見積もりが立つ
  - **5 人全員を斬った場合**という終了条件がはっきり定義できる
  - リプレイ性は家臣の顔ぶれではなく、**献上品の中身**で担保する
- **5 人目（宰相）だけは、まともな提案をしてくる。** これが緊張を生む（[02-mechanics.md](02-mechanics.md#5-人目宰相まとも枠)）。

## ゲーム名

# 下民ショッピング

- 献上しに来る家臣たちの側から見たタイトル。**王子のわがままに下々の者が振り回される**構図が一語で出る
- 「下民」と「ショッピング」の落差で、タイトルだけで笑いどころが伝わる
- 検討した対抗案: 「打ち首ショッピング」「わがままショッピング」
- 「下民」は人を見下す語なので、**ゲーム内では家臣を実際に貶める描写はしない**（打ち首もコミカルに留める）。
  タイトルの強さと中身のコミカルさのギャップで見せる
