# 下民ショッピング ドキュメント

**下民ショッピング** — 王子のわがままに、下々の者が振り回されるゲーム

内定者ハッカソン 2026 / リポジトリ: `pub-internship2026-hackathon-aerial_prince`

## これは何のゲームか

プレイヤーは**わがままな王子様**。無茶な要求を口にすると、家臣たちが献上品を持って謁見の場に**列をなして**やってくる。
気に入らない献上品は片っ端から**「打ち首だ！」**。最後に採用した一品と、斬った数によって、その後の国の運命が語られる。

コアの快感は 3 つ。

1. わがままを言う気持ちよさ
2. 大量の提案をバッサバッサと切り捨てる気持ちよさ（打ち首）
3. 提案そのもののバカバカしさ（実在商品のズレた献上）

## 前提・制約

- **デプロイはすべて Snowflake 内で完結させる必要がある**（詳細は [06-snowflake.md](06-snowflake.md)）
- 献上品は**できるだけ実在する商品**を出したい（詳細は [05-data.md](05-data.md)）
- **まず Streamlit でシンプルに一周遊べるものを作る**（詳細は [07-implementation-plan.md](07-implementation-plan.md)）
- 家臣（献上しに来る人）は **5 人固定**。**5 人目だけは「まともな提案」をする**

## ドキュメントの書き方ルール

- 外部の情報（製品仕様・API・データセット）に言及するときは、**その場に URL を書く**。まとめては [references.md](references.md)。
- 一次情報（公式ドキュメント）と二次情報（ブログ・まとめ記事）を区別して書く。
- 裏が取れていないことは「**要確認**」と明記する。
