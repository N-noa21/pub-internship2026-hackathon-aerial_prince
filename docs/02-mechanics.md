# 02. コアメカニクス

> 一覧に戻る: [README.md](README.md) ／ 前: [01-concept.md](01-concept.md) ／ 次: [03-presentation.md](03-presentation.md)

## わがまま入力

- 自由入力のプロンプト。1 プレイにつき 1 回。
- 王子っぽい口調のサンプル（「〜が欲しいのじゃ」）をプレースホルダで提示する。
- **お題ガチャ**（ランダムなわがまま）も用意すると、入力に迷う客層を拾える。展示では効く。

## 家臣（5 人固定）

1 回のわがままに対して、**必ず 5 人**が献上品を持って参上する。
同時にドンと出すのではなく、**列に並ばせて 1 人ずつ謁見させる**（同時提示は間延びする）。

| 順 | 属性 | 口調・キャラ | 献上品の傾向 |
| --- | --- | --- | --- |
| 1-4 | 商人 | 押しが強い、通販番組 | 型番付きの実売品、まとめ買い、業務用サイズ |
| 1-4 | 貴族 | 気取っている、見栄っ張り | 高級品・ブランド・インテリア。値段だけ立派 |
| 1-4 | 騎士 | 実直で忠誠心が高い | 装備・道具・アウトドア用品。実用一辺倒 |
| 1-4 | 農民 | 素朴で必死、方言 | 食品・農産物・生活雑貨。的外れだが真心はある |
| **5** | **宰相** | 落ち着いている、常識人 | **わがままに対する現実的で妥当な回答**（下記） |

- 前半 4 人の順番はランダムでよい。**宰相は必ず最後**。
- 差し替え候補として **錬金術師**（サプリ・開運アイテム。怪しい早口）と **学者**（書籍・図鑑。理屈っぽい）を控えに置く。
- 5 人は毎回同じ顔ぶれなので、**キャラの立て方に投資する価値がある**（立ち絵・口癖・登場音）。

## 5 人目（宰相）＝まとも枠

**最後の 1 人だけは、ふざけずに「まともな提案」を持ってくる。**

| わがまま | 宰相の回答 |
| --- | --- |
| 城が欲しい | 城の見学ツアー（一泊二日） |
| 白馬に乗りたい | 乗馬クラブの体験レッスン |
| 黄金が欲しい | 純金積立（月々一万円から） |
| 不老不死の薬をよこせ | 人間ドックの受診券 |
| 世界を征服したい | 世界一周旅行のパンフレット |
| 最強の剣を持て | 剣道具一式（防具＋竹刀） |

### なぜこれが効くのか

- **プレイに緊張が生まれる。** 前半でふざけた品を斬り続けると、最後にまともな品が来る。
  しかし**5 人全員を斬れば何も残らない**。「引っ張るか、手を打つか」のジレンマができる。
- **オチとして強い。** ふざけた献上が 4 回続いた後の「正論」は、それ自体が笑いになる。
- **エンディングの分岐がきれいに割れる。** 宰相を採用＝堅実な王子、宰相を斬る＝型破りな王子。
  診断レポートの軸として一番わかりやすい（[04-ending.md](04-ending.md)）。

### 単調化への対策

毎回まったく同じだと「宰相まで待つ」が最適解になり、ゲームが死ぬ。歯止めを用意する。

| 対策 | 内容 |
| --- | --- |
| **まともだが夢がない** | 正しいが地味。選ぶと後日談も堅実で退屈になる（＝選びたくならない） |
| **欠点を持たせる** | 高すぎる／時間がかかる／条件が細かい。正論だが飲みにくい |
| **たまに裏切る** | 低確率で宰相もふざける。「今日は宰相までおかしい」がネタになる |
| **前半にも当たりを混ぜる** | ふざけた品の中にも「これはこれで欲しい」ものを混ぜ、待つのが常に最適にならないようにする |

## 献上品（提案される商品）

- **できるだけ実在する商品**を出す。現実にあるものだからこそ笑える。データの出どころは [05-data.md](05-data.md)。
- 商品画像があるとベター。無い場合の扱いも [05-data.md](05-data.md) を参照。
- 狙いは「わがままには一応答えているが、明らかにスケールが違う」ズレ。

### ズラし方の型（プロンプト設計の中心）

ここがこのゲームの面白さの中心。LLM への指示は、この型を明示的に与える。

| 型 | やり方 | 例 |
| --- | --- | --- |
| スケールダウン | 本物 → おもちゃ・ミニチュア | 城 → LEGO のお城セット |
| 素材化 | 生き物・概念 → 加工品 | 白馬 → 馬刺し／馬油シャンプー |
| 同音・語呂 | 言葉だけ合っている | 王冠 → ビール瓶の王冠、星 → ミシュランの星 |
| 日用品への翻訳 | 概念 → 家にある物 | 時を止める → 冷凍庫、軍隊 → 将棋の駒 |
| 体験に変換 | モノ → 体験チケット | 空を飛びたい → パラグライダー体験 |
| 物量で殴る | 業務用・大容量 | ごちそう → 業務用冷凍唐揚げ 1kg |
| 象徴の代替 | 効能だけ似ている | 不老不死の薬 → 栄養ドリンク |

**5 人目の宰相だけは、ふざけずに現実的な回答**を返す。

## 打ち首

- 気に入らない献上品は「打ち首だ！」で退場。
- **打ち首の演出がこのゲームの肝**。演出の中身と実装方針は [03-presentation.md](03-presentation.md#打ち首アニメーション) にまとめた。
- 直接的・残虐な表現は避け、**理不尽だがコミカルな退場**にする。
- **連続で斬るほど演出が派手になる**（コンボ）と、斬る快感が伸びる。

## 判決理由（任意入力）

打ち首・採用のときに「**なぜ斬った？**」「**なぜ選んだ？**」を一言もらえると、
**最後のストーリーが一気に作りやすくなる**。プレイヤーの言葉がそのまま後日談の根拠になり、
生成が「それっぽい話」から「自分の話」に変わる。

- **必ず任意にする**。入力は最初の 1 回だけ、という原則を壊さないため、スキップが最短ルートであるべき。
- 入力コストを下げる工夫：
  - **ワンタップの定型理由**を主役にする（「安っぽい」「無礼者」「解釈違い」「趣味ではない」「高すぎる」）
  - 自由入力欄はその横に小さく置く。書きたい人だけ書く
  - 定型理由を王子の口調で書くと、選ぶこと自体が楽しい
- 得られるもの：
  - 後日談に**プレイヤーの言葉を引用**できる（「"安っぽい" と言い放った王子は…」）
  - 診断レポートの評価軸を、行動だけでなく**理由から推定**できる（[04-ending.md](04-ending.md)）
  - 打ち首演出の出し分けに使える（「無礼者」→ 大砲、「安っぽい」→ 却下スタンプ）
- 一言も書かなかったプレイヤー用に、**無言で斬り続けた王**という専用の締め方を用意しておくと穴が開かない。

## 終了条件

家臣が 5 人固定なので、終わり方は次の 2 つに限定される。

| 終わり方 | 条件 | 締め |
| --- | --- | --- |
| **採用** | 5 人のうち誰かの献上品を選ぶ | 選んだ品に応じた後日談 |
| **全員打ち首** | 5 人全員を斬る（宰相の正論すら退ける） | 「王子は何も手に入れなかった」ルート。専用エンディングを用意する |

- 全員斬りは**バッドエンドではなく、狙って取りに行きたくなるオチ**にすると、2 周目の動機になる。
- 「もう一列呼ぶ」案は、テンポが伸びる割に得るものが少ないので現時点では採らない。
