# 04. エンディング・診断レポート

> 一覧に戻る: [README.md](README.md) ／ 前: [03-presentation.md](03-presentation.md) ／ 次: [05-data.md](05-data.md)

採用した献上品とプレイ内容から「**あなたはこういう王子ですね**」という診断レポートを出す。
見せ方は**エンタメ寄り**にしたい。真面目な分析ではなく、雑誌の性格診断・通信簿・国家ステータス画面のノリ。

## 生成の材料

| 材料 | 使いどころ |
| --- | --- |
| 最初のわがまま | 王子の器の大きさ・方向性 |
| 打ち首の数と相手（属性） | 暴君度、誰に冷たい王か |
| 採用した献上品 | 結末そのもの（何を手に入れた国か） |
| **判決理由（任意）** | 王子の人格。後日談に**そのまま引用**できる |

家臣が 5 人固定なので、「誰を斬って誰を残したか」が毎回同じ軸で比較できる。
**判決理由（[02-mechanics.md](02-mechanics.md#判決理由任意入力)）が入ると質が跳ね上がる**ので、入力を促す価値は高い。

## 評価軸の案（未決）

打ち首数だけだと単調なので、複数軸を組み合わせる。

| 軸 | 何から計算するか | 出方の例 |
| --- | --- | --- |
| 暴君度 | 打ち首の数・連続数 | 「家臣の生存率 20%」 |
| 浪費度 | 採用した献上品の価格 | 「国庫からの支出 ¥398」 |
| 審美眼 | 採用品がわがままとどれだけズレていたか | 「見る目がない」 |
| 決断力 | 採用までにかかった時間 | 「即断即決」「優柔不断」 |
| 民の信頼 | 農民の献上品を採用したか／斬ったか | 「民の心、離れつつあり」 |
| 好みの属性 | どの属性の家臣を残したか | 「商人にだけ甘い王子」 |
| 堅実さ | **宰相（まとも枠）を採用したか、斬ったか** | 「正論を斬り捨てた王」「宰相に頼りきりの王」 |
| 口の悪さ | 判決理由の言葉づかい | 「暴言の記録: 4 件」 |
| こだわり | 理由を書いた回数・一貫性 | 「理由なき粛清」「一貫した美学」 |

- 最後に**称号**を与えると持ち帰りやすい（例: 「シルバニアの暴君」「値札を見ぬ王」「無言の粛清者」）。
- スコアはレーダーチャートや国家ステータス画面風に出すと、それだけで画になる。
- 数値は**厳密さより語感**を優先する。エンタメなので、笑える単位・笑える桁にする。

## 後日談

結果に応じた**その後の国の運命**を語らせる。

### 方針: リアルさ × エンタメ

LLM に自由に書かせると、それっぽいが散らかった文章になりやすい。
**「寓話の型」と「史実によくある王侯の末路の型」を下敷きにして、そこにプレイ結果を流し込む**と、
短くても話として成立し、しかも笑える。

- **寓話** … 因果がはっきりしていて、オチが強い。短文で決まる
- **史実の類型** … 「実際にありそう」という手触りが出る。エンタメ一辺倒にならない
- **献上品のリアルな情報**（実在商品・実際の価格）… 荘厳な文体とのギャップがそのまま笑いになる

### 下敷き A: 寓話の型

| 寓話の型 | 話の骨格 | 効かせどころ |
| --- | --- | --- |
| ミダス王の黄金 | 願ったものが手に入りすぎて身を滅ぼす | 大きなわがままを、身の丈に合わない品で叶えたとき |
| 裸の王様 | 誰も本当のことを言わなくなる | **全員打ち首ルートに最適**。諫言する者が消えた国 |
| イカロス | 増長して高く飛びすぎ、墜ちる | 打ち首が多く、かつ豪華な品を選んだとき |
| 三つの願い | 貴重な機会をつまらないものに浪費する | 安い品・どうでもいい品を採用したとき |
| わらしべ長者 | 些細な物が巡り巡って富になる | 農民の素朴な品を採用したときのハッピーエンド |
| 金の斧・銀の斧 | 正直・謙虚が報われる | 高級品を退け、質素な品を選んだとき |
| 北風と太陽 | 力より優しさが人を動かす | 打ち首が少なかったとき |
| アリとキリギリス | 備えの有無が後で効く | 実用品を選んだか、嗜好品を選んだか |
| 王様の耳はロバの耳 | 隠しごとは必ず漏れる | 判決理由が辛辣だったとき |

- 型は**エンディングマスタとしてテーブルに持つ**。プレイ結果（打ち首数・採用品・属性・判決理由）で型を選び、
  **LLM にはその型に沿って具体化させる**。完全な自由生成より品質が安定する。
- 寓話の原典テキストが必要になったら、著作権の切れたものは青空文庫などから当たれる（<https://www.aozora.gr.jp/>、収録の有無は要確認）。
  ただし**引用しなくても、型さえ借りれば成立する**。

### 下敷き B: 史実によくある王侯の末路の型

「実際の王子のストーリー」を参考にすると、後日談に手触りが出る。

| 類型 | 何が起きるか | 効かせどころ |
| --- | --- | --- |
| 財政破綻 | 浪費が国庫を傾け、増税から民の不満へ | 高額な品を採用したとき |
| 継承権の喪失 | 素行を理由に廃嫡され、静かな場所へ送られる | 打ち首が多いとき |
| 側近の粛清と孤立 | 諫める人材を失い、判断を誤る | 特定の属性ばかり斬ったとき |
| 傀儡化 | 実権を家臣に握られ、名前だけの王になる | 決断が遅い／理由を書かないとき |
| 意外な功績 | 気まぐれに選んだ品が流行し、産業が興る | ズレた品を採用したときの当たりルート |
| 民との和解 | 素朴な品を選んだことが伝わり、支持を得る | 農民を残したとき |

**実在人物の扱いのガイドライン:**

- **実在の人物名を直接出して戯画化するのは避ける。** 誰かの子孫や関係者が見る可能性があり、笑いの筋としても弱い。
- 使うのは**「史実によくある型」**まで。固有名詞ではなく構造を借りる。
- 国名・王朝名もぼかす。舞台は「どこかの王国」でよい。

### リアルさの出し方

- 採用した献上品の**実際の価格**を、そのまま国家の支出として語る（「国庫からの支出 ¥398」）
- 実在商品の**スペックや商品説明を、荘厳な文体で読み上げる**（「その者、二層構造にして保温性に優れ…」）
- 数字は本物、語り口は歴史書。**この落差が一番笑える**ので、価格・型番・容量はできるだけ本物を使う

### 専用エンディング

| ケース | 締め方 |
| --- | --- |
| 5 人全員を打ち首 | 「裸の王様」型。諫言する者が消えた国。狙って取りに行きたくなるオチにする |
| 判決理由を一度も書かなかった | 「無言で斬り続けた王」。傀儡化の類型と相性が良い |
| 農民だけを残した／斬った | 民との関係に全振りした後日談 |

- 分岐の軸（案）: 打ち首数、採用した献上品と献上した家臣の属性、わがままの規模、判決理由の口の悪さ。

## カメラ写真の再利用

- 冒頭で作った**王子アバターをエンディングでも使う**と一気に締まる。
  - 「肖像画」として額縁に飾る／後日談の挿絵にする
  - 結末に合わせて状況を変える（玉座を追われた王子、年老いた王 など）
- 画像変換のパイプラインを使い回せるので追加コストは小さい（[03-presentation.md](03-presentation.md#王子アバターカメラ機能)）。
- **アバター＋称号＋スコアを 1 枚のシェア画像**にまとめると持ち帰ってもらえる。展示との相性が良い。
- ただし画像生成の実現手段自体にリスクがあるため（[06-snowflake.md](06-snowflake.md#生成-ai-の置き場所)）、
  **写真が無くても成立するレイアウト**を先に作り、写真は乗ればボーナス、という順序で組む。
